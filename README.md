## About

This repository is the public release registry for **LUNEVON** products.

It contains release metadata, public changelogs, permission notes and verification information intended for users, stores and external reviewers.

**It does not contain product source code, signing material, credentials or private build configuration.**

## Verification

Where a release checksum is publicly available, it is recorded in the corresponding release document.

A checksum is published only after the exact final release artifact has been built, signed and verified. Placeholder or historical hashes are never reused for a newer release.

---

## Permissions philosophy

LUNEVON applications are designed around **minimal permissions and explicit user control**.

Permission notes in this repository describe the public behavior of each release. Optional features should remain optional, and sensitive permissions must have a clear user-facing purpose.

---

## Repository scope

Public content may include:

- release versions;
- public changelogs;
- user-facing permission descriptions;
- release verification metadata;
- product and store links;
- checksums of finalized public artifacts.

Not published here:

- application source code;
- internal architecture and implementation details;
- signing keys or certificates;
- passwords, tokens or credentials;
- private build/release automation;
- unreleased internal material.
