# Lunevon DI 1.0.9

**Status:** Current release  
**Languages:** Russian / English

## Overview

Lunevon DI 1.0.9 provides device specifications and current readings across seven primary areas:

- overview;
- CPU;
- RAM;
- network;
- battery;
- storage;
- device information.

The application can export technical information and current-state reports locally in PDF or TXT format.

## Release highlights

- Updated LUNEVON mobile design foundation.
- Improved CPU information presentation.
- Refined Settings, Contacts, Help and About surfaces.
- Improved RU / EN consistency.
- Improved technical guidance for CPU, RAM, network, battery, storage and device information.
- Optional quick-access notification remains user-controlled.

## Permissions

| Permission | Purpose | Required for core use |
|---|---|---|
| `ACCESS_NETWORK_STATE` | Reads current network connection state for the Network section. | Used for network information |
| `POST_NOTIFICATIONS` | Optional quick-access notification. | **No** |

### Not requested

Lunevon DI does not request:

- Internet access;
- location;
- storage-wide access;
- camera;
- microphone;
- phone-state access;
- usage statistics;
- accessibility service access.

Report export uses the Android system destination picker instead of broad storage access.

## Network behavior

The application does **not** request the Android `INTERNET` permission.
