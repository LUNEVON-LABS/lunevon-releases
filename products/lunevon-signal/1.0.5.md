# Lunevon Signal 1.0.5

**Status:** Current release  
**Languages:** Russian / English

## Overview

Lunevon Signal visualizes current Wi-Fi signal conditions directly on the device.

The interface includes:

- RSSI in dBm;
- signal quality;
- signal trend;
- recent signal trace;
- Wi-Fi band;
- Wi-Fi standard;
- negotiated RX / TX link information.

## Release highlights

- Finalized LUNEVON design-system alignment.
- Fixed public release numbering for the current store build.
- Refined main-screen telemetry hierarchy.
- Improved Wi-Fi signal trace presentation.
- Added contextual explanations for RSSI, signal trend and link information.
- Improved accessibility labels for live technical values.
- Improved behavior when Wi-Fi is used underneath a VPN connection.
- Persistent quick-access notification remains opt-in.

## Permissions

| Permission | Purpose | Required for core use |
|---|---|---|
| `ACCESS_NETWORK_STATE` | Reads current connectivity state. | Yes |
| `ACCESS_WIFI_STATE` | Reads current Wi-Fi connection information. | Yes |
| `POST_NOTIFICATIONS` | Optional persistent quick-access notification/status icon. | **No** |

### Not requested

Lunevon Signal does not request:

- Internet access;
- location;
- camera;
- microphone;
- storage-wide access;
- wake-lock/background-monitoring permission.

## Network behavior

Signal measurements and Wi-Fi link information are processed locally on the device.

The application does **not** request the Android `INTERNET` permission.
