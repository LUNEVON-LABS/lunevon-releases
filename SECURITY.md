# Security

## Reporting

Please do **not** disclose security-sensitive findings in a public GitHub issue.

Send security or privacy-related reports directly to:

**support@lunevon.com**

Include:

- affected LUNEVON product;
- version;
- device / Android version where relevant;
- concise reproduction steps;
- screenshots or logs only when they do not contain personal secrets.

Do not send passwords, private keys, access tokens or unrelated personal data.

## Scope of this repository

This repository contains public release metadata only. LUNEVON product source code and private signing infrastructure are not published here.
